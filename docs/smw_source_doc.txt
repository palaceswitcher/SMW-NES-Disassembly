-----Background Info-----
For whatever reason, Hummer Team left chunks of source code in the form of assembler object files in various parts of the CHR. They were likely intended for use with 2500 AD Linker, the suite Hummer Team used, though the specific format for this is unknown and full object files have yet to be reconstructed from the CHR data. Below is a note of every interesting label found amidst the object data, as well as binary chunks of an intermediate build of the game between the prototype and final game.

-----Binary Chunks-----
CHR Bank 003 - Bank 56 ($8C00-$8FFF)
CHR Bank 007 - Bank 56 ($9C00-$9FFF)
CHR Bank 009 - Bank 57 ($A400-$A7FF)
CHR Bank 011 - Bank 57 ($AC00-$AFFF)
CHR Bank 014 - Bank 57 ($B800-$BBFF)

-----Enemy List-----	
At 0x90010, there is a truncated list of pointers to the sprite drawing code for several objects. Some pointers differ from those and the final game.
Bulu = Buru/Charging Chuck
Calon = Karon/Dry Bones
Honmate = Honemetto/Bony Beetle
Telisa = Teresa/Boo Buddy
Killer = Bullet Bill

-----Assembler Label Format-----
Most symbol entries are 59 bytes long, with the first 32 bytes containing the name as a string, followed by the address of the symbol and some other data. Some entries are a bit longer (Possibly overwritten?) and may have more bytes for the symbol name. Either way, the address should be the first non-zero value after the symbol's name string.
